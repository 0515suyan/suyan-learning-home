# 夙烟の教学之家

纯前端 RoboCup 备赛教学网站。双击 `index.html` 即可打开；不需要安装依赖或启动后台。

包含六个学习区、47 节可展开课程：RoboCup 2D（6）、FIRA（4）、灵巧手（4）、Linux（8）、Python（10）、ROS 2（15）。每节包含目标、前置条件、原理、示例、讲解、预期结果、排错、练习、答案和公开来源。另有搜索、章节跳转、代码复制、本地完成记录与可暂停的球场示意动画。

文件：`index.html` 页面结构；`style.css` 和 `teaching.css` 视觉与阅读布局；`curriculum.js` 三个赛项及课程组件；`foundations.js` Linux 与 Python；`ros-course.js` ROS 2；`app.js` 课程渲染和交互；`hero.js` 封面动画。

网页字体可选地从 Google Fonts 加载，网络不可用时使用本机中文字体，不影响内容和操作。不依赖外部图片或前端框架。

教程不依赖作者的私有仓库或机器目录。组件通过每节公开来源下载；代码示例完整展示。FIRA 当届平台的稳定公开安装包直链尚未核实，页面给出赛事官方获取入口，未以 5v5 平台或第三方客户端充当平台。厂家型号和 ROS 发行版兼容性需独立核对，通用示例不声称是三指手的完整赛事场景。

页面中的“已完成”由学习者自行标记，不实际执行系统命令；记录仅保存在当前浏览器。新版课程重写后使用独立的进度记录，避免把旧 12 节的完成状态误记到新课。隐私模式、清理数据或本地文件限制可能影响持久保存。

核对日期：2026-11-20。安装步骤依据公开上游资料整理，未在全新 Ubuntu 上逐项重新安装验收。比赛规则、设备条件以当届官方资料为准。

发布前已检查课程结构、来源、目录跳转、搜索、进度和多宽度展开布局；14 段 Python 示例通过语法检查，8 个独立练习输出通过比对，59 段 Bash 示例通过语法检查。这些检查不等同于 ROS、FIRA 或硬件环境安装验收。

GitHub Pages 发布配置：`main` 分支根目录，`.nojekyll` 禁用 Jekyll 处理。修改文件并推送到 `main` 后，GitHub Pages 会重新发布；本网站无需构建步骤。
